Conectar Google Drive

Esta versión necesita un ID de cliente OAuth de Google para acceder de forma privada a tus canciones. No introduzcas tu contraseña aquí.

Primero hay que habilitar Google Drive API y crear un ID de cliente de tipo Aplicación web en Google Cloud. En “Orígenes autorizados de JavaScript”, añade el origen de tu página publicada en GitHub Pages.
